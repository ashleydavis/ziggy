# 35-zoom-keys

Proves that the View menu's zoom shortcuts work when pressed as a user presses them: Ctrl+Plus zooms in, Ctrl+Minus zooms out, Ctrl+0 puts the frontend's area back to its normal size.

It takes no arguments. `run.sh` runs it on a desktop platform. To run it alone:

```
ZIGGY_SMOKE_SCENARIO=35-zoom-keys bun run test:smoke
```

See [the run documentation](../../run.md).
