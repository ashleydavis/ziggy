# hello-shortcut

Hello world example: change it into your own smoke test, or delete it.

Presses Ctrl+Shift+H, the shortcut of the template's Say Hello From an Action action, as a user does, through the native app, and checks the line the action's handler writes. It runs only on Linux, Windows and macOS, because a mobile has no shortcuts.

It takes no arguments. Run it with:

```
bun run test:smoke -- hello-shortcut
```

See [the run documentation](../../run.md).
